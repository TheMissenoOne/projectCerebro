MODOS DE DANO

Temporário: Dano que desaparece após a cena (atordoamento, medo, etc.)

Persistente: Dano que persiste até o fim do combate (ferimentos, condições)

Permanente: Dano que não desaparece (ferimentos sérios, perda de capacidades)

ACTION TABLE — Colunas de Valor de Oposição (OV)
+5: uma mudança de coluna para cada +5.   C: Cancelar — uma linha +5 cancela uma coluna +5.   O valor 11 na diagonal marca AV = OV.
RESULT TABLE — Colunas de Valor de Resistência (RV)
×: para cada 5 APs de Effect Value acima de 60, aumente os RAPs em 5.   A: All — RAPs iguais ao Effect Value.   N: No Effect.   C: Cancelar.
